# DK Island Swing - HEAVY METAL VERSION 🎸🦘

A heavy metal reinterpretation of the classic Donkey Kong Country theme "DK Island Swing" using the Web Audio API.

## Features

- 🤘 Distorted guitar with overdrive
- 🎸 Aggressive palm-muted rhythm
- 🥁 FAST double-bass drumming (180 BPM!)
- 🎸 Intense guitar solo
- 🔥 Fire visualizer
- 🎮 Pure nostalgic heavy metal energy

## Usage

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge)
2. Click **"🤘 PLAY 🤘"** to rock out
3. Click **"STOP"** to end the madness

## Technical Details

- Built with pure **HTML/CSS/JavaScript**
- Uses **Web Audio API** for real-time audio synthesis
- No external libraries or audio files
- All audio generated programmatically:
  - Sawtooth waves for distorted guitars
  - Square waves for bass
  - Sine/triangle waves for drums
  - Wave shapers for distortion effects

## The Metal Treatment
